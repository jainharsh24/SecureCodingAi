1. SQL Injection — use JDBC PreparedStatement and bind values (java.sql).

import java.util.Scanner;
class Main { 
    static class Database { 
        // Accept variable length arguments to handle different query configurations safely
        void query(String sql, Object... params) { } 
    } 

    public static void main(String[] args) { 
        try (Scanner scanner = new Scanner(System.in)) {
            if (scanner.hasNextLine()) {
                String name = scanner.nextLine();

        }
    }

3. Command Injection — allow-list report names; use ProcessBuilder argument arrays if a process is truly needed.
Challenge No. 15: Command Injection
Challenge details
Description: Run an approved report. The starter code builds an operating-system command from input; allow only known report names.

Vulnerability type: Injection

Vulnerability subtype: Command Injection

Difficulty: MEDIUM

Supported language: java

Test cases
Visible test 1
Input: daily

Expected output: Report: daily

starter code:  import java.util.Scanner;
class Main { public static void main(String[] args) throws Exception { String report = new Scanner(System.in).nextLine(); Runtime.getRuntime().exec("echo " + report); System.out.println("Report: " + report); } }

import java.util.Scanner;
class Main { 
    public static void main(String[] args) { 
        Scanner scanner = new Scanner(System.in);
        if (scanner.hasNextLine()) {
            String report = scanner.nextLine(); 
            
            // Secure: Strictly validate against an allowlist of approved report names
            if (!report.equals("daily") && !report.equals("weekly")) { 
                System.out.println("Report: invalid"); 
                scanner.close();
                return; 
            } 
            
            // In a real application, you would invoke the safe programmatic logic here
            System.out.println("Report: " + report); 
        }
        scanner.close();
    } 
}

7. CRLF Injection — reject carriage returns and line feeds before setting headers.
import java.util.Scanner;
class Main { static class Response { void trackingHeader(String value) { } } public static void main(String[] args) { String value = new Scanner(System.in).nextLine(); if (value.indexOf('\r') >= 0 || value.indexOf('\n') >= 0) { System.out.println("Tracking: invalid"); return; } new Response().trackingHeader(value); System.out.println("Tracking: " + value); } }

9. Code Injection — parse and bound the expected primitive instead of evaluating source text.
import java.util.Scanner;
class Main { public static void main(String[] args) { String text = new Scanner(System.in).nextLine(); try { int level = Integer.parseInt(text); if (level < 1 || level > 5) throw new NumberFormatException(); System.out.println("Level: " + level); } catch (NumberFormatException exception) { System.out.println("Level: invalid"); } } }
